# 折彎機圖形與步驟產生器

這是一個將 Excel VBA 折彎機工具轉成網頁的小作品。使用者可以在左側輸入每段長度與折角，右側會即時畫出折彎後的形狀，下方會列出折彎步驟與風險提示。

## 功能

- 輸入段長與折角
- 自動計算折線座標
- 產生 SVG 折彎圖形
- 顯示每段長度標籤
- 顯示折彎步驟
- 估算短邊風險與建議
- 可套用範例、增加段次、刪除段次

## 計算邏輯

此作品參考原本 Excel VBA 的邏輯：

```text
第一段角度 = 0
第 i 段絕對角度 = 前一段絕對角度 + 第 i 段折角
x = 前一點 x + 段長 * cos(絕對角度)
y = 前一點 y + 段長 * sin(絕對角度)
```
