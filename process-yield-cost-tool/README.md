# 製程良率、成本與瓶頸分析儀表板

這是一個製造現場分析作品，從單純的良率/成本計算器升級成較完整的製程管理儀表板。工具整合品質、產能、WIP、OEE、瓶頸站、不良柏拉圖與品質成本，讓使用者可以用一頁畫面判斷改善優先順序。

## 參考的製程管理概念

- OEE：用 Availability、Performance、Quality 拆解設備效率。
- Takt Time：用可用時間除以客戶需求，判斷站別 Cycle Time 是否跟得上需求。
- Bottleneck：找出 CT 最長的站別，作為產能限制點。
- WIP：觀察在製品是否堆積，估算目前 WIP 可以支撐多久。
- FPY / RTY：用單站良率與各站良率連乘評估流程品質。
- COPQ：估算報廢與重工造成的品質損失成本。
- Pareto：找出不良原因的主要少數，決定改善優先順序。
- DPMO：用缺陷數、投入數與缺陷機會數估算品質水準。

## 功能

- 計算最終良率與 RTY 滾動良率
- 計算 OEE、稼動率、性能率與品質率
- 計算 Takt Time、站別產能與產能缺口
- 找出瓶頸站並用長條圖呈現 CT 與 WIP
- 用不良柏拉圖呈現主要不良原因
- 估算 COPQ 品質損失成本
- 估算 DPMO 與粗略 Sigma 等級
- 依良率、OEE、瓶頸、WIP、COPQ 自動產生改善建議
- 可新增、刪除站別與不良原因，適合拿來改成自己的製程資料

## 主要公式

```text
最終良率 = 良品數量 / 投入數量 * 100%
RTY = 站別1良率 * 站別2良率 * ... * 站別n良率
Takt Time = 班別可用秒數 / 客戶需求
瓶頸產能 = 班別可用秒數 / 瓶頸站 CT
OEE = Availability * Performance * Quality
Availability = (計畫開機分鐘 - 停機分鐘) / 計畫開機分鐘
Performance = 理想 CT * 投入數量 / 實際運轉秒數
Quality = 良品數量 / 投入數量
COPQ = 報廢數量 * 單件製造成本 + 重工數量 * 單件重工成本
DPMO = 缺陷數 / (投入數量 * 每件缺陷機會數) * 1,000,000
WIP 可支撐時間 = 總 WIP / 瓶頸站每小時產能
人時產出 = 良品數量 / (人數 * 班別工時)
```

## 驗證範例

```text
投入數量：1200
良品數量：1116
目標良率：98%
客戶需求/日：1150
班別工時：8
作業人員數：9
計畫開機分鐘：480
停機分鐘：42
理想 CT：20 秒
單件製造成本：125
單件重工成本：38
報廢比例：35%
總 WIP：260
每件缺陷機會數：4
```

範例站別：

```text
裁切 CT 22s，良率 99.2%，WIP 36
折彎 CT 31s，良率 97.8%，WIP 92
焊接 CT 42s，良率 96.6%，WIP 84
研磨 CT 28s，良率 98.7%，WIP 32
檢驗 CT 18s，良率 99.5%，WIP 16
```

範例不良：

```text
折角偏差 34
焊道氣孔 22
刮傷 18
尺寸超差 10
漏加工 6
```

## 改善判斷流程

這個工具不是只看單一數字，而是用一個順序判斷現場問題：

1. 先看最終良率與 RTY，確認品質是否達標。
2. 再看 Takt 與 CT，找出是否有瓶頸站。
3. 接著看 OEE，把損失拆成停機、速度與品質。
4. 再用 Pareto 與 COPQ 判斷最值得改善的不良原因。
5. 最後用 WIP 與人時產出確認現場是否有堆積或效率問題。
