# 製程良率、WIP 與人力效率分析工具

這是一個結合工業管理、品質管理與現場管理概念的小作品。使用者可以輸入生產總數、良品數量、不良品數量、WIP 在製品數、作業人員、工時、標準產能與成本資料，系統會自動計算良率、不良率、品質損失成本、WIP 可支撐時間與人力產出效率。

## 功能

- 計算實際良率與不良率
- 估算品質損失成本
- 判斷是否達到目標良率
- 計算人均產出與人時產出
- 估算 WIP 可支撐時間
- 計算產能達成率
- 依照良率、WIP 與產能狀況提供改善建議

## 公式

```text
實際良率 = 良品數量 / 生產總數 * 100%
不良率 = 不良品數量 / 生產總數 * 100%
品質損失成本 = 不良品數量 * (單件製造成本 + 單件重工成本)
人均產出 = 良品數量 / 作業人員數
人時產出 = 良品數量 / (作業人員數 * 班別工時)
WIP 可支撐時間 = WIP 在製品數 / 每小時良品產出
產能達成率 = 每小時良品產出 / 標準產能每小時 * 100%
```

## 驗證範例

```text
生產總數：1000
良品數量：940
不良品數量：60
目標良率：98%
單件製造成本：120
單件重工成本：35
WIP 在製品數：180
作業人員數：8
班別工時：8
標準產能/小時：130
```

計算結果：

```text
實際良率：94.00%
不良率：6.00%
品質損失成本：$9,300
人均產出：117.5 件/人
人時產出：14.69 件/人時
WIP 可支撐時間：1.53 小時
產能達成率：90.38%
```
