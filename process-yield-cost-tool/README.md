# 製程良率與不良成本分析工具

這是一個結合工業管理與品質管理概念的小作品。使用者可以輸入生產總數、良品數量、不良品數量、目標良率與成本資料，系統會自動計算實際良率、不良率、品質損失成本，以及距離目標良率的差距。

## 功能

- 計算實際良率
- 計算不良率
- 估算品質損失成本
- 判斷是否達到目標良率
- 依照結果提供改善建議

## 公式

```text
實際良率 = 良品數量 / 生產總數 * 100%
不良率 = 不良品數量 / 生產總數 * 100%
品質損失成本 = 不良品數量 * (單件製造成本 + 單件重工成本)
```

## 驗證範例

```text
生產總數：1000
良品數量：940
不良品數量：60
目標良率：98%
單件製造成本：120
單件重工成本：35
```

計算結果：

```text
實際良率：94.00%
不良率：6.00%
品質損失成本：$9,300
距離目標差距：4.00%
```
